# Contracts

This feature is designed as a desktop application with no external HTTP, CLI, or integration contract defined in the current scope.

The domain contract is captured in the feature specification and the data model. The core interfaces are business flows such as account sign-in, group membership, expense submission, approval actions, balance calculation, payment settlement, and report generation.

No external service contract is required for the Swing MVP because the application is intended to operate within a local desktop environment and does not expose a public API in this planning stage.
